# 키워드 조사 스크립트

네이버 블로그(쇼핑커넥트) 주제를 고르기 위해 키워드별 **검색량, 경쟁도, 구매 의도**를 숫자로 뽑는 도구입니다.
외부 패키지 없이 Python 3 기본 기능만 씁니다.

## 무엇을 모으나

| 열 | 출처 | 의미 |
|---|---|---|
| 월간검색수 (PC/모바일) | 검색광고 API `keywordstool` | 최근 30일 검색 횟수. 10 미만은 5로 계산 |
| 블로그문서수 | 네이버 블로그 검색 API `total` | 이미 쓰인 경쟁 글의 양 |
| 검색수/문서수 | 계산 | 클수록 찾는 사람에 비해 글이 적은 틈새 |
| 모바일1위입찰가 | 검색광고 API `average-position-bid` | 광고주가 이 키워드에 거는 돈. 높을수록 실제로 팔리는 키워드 |
| 구매의도 | 키워드에 추천·비교·가격·순위 같은 말이 있는지 | Y/N |
| 기회점수 | 계산 | log(검색수) × min(검색수/문서수, 5) × (구매의도면 1.5). 후보를 추리는 1차 점수일 뿐 절대 기준이 아님 |

## 준비

키는 **채팅에 붙여넣지 말고** 클라우드 환경 설정의 환경 변수로 등록합니다. 등록 후 새로 연 세션부터 적용됩니다.

| 환경 변수 | 어디서 받나 | 필수 |
|---|---|---|
| `NAVER_SEARCHAD_CUSTOMER_ID` | 검색광고 광고주센터 → 도구 → API 사용 관리 | 필수 |
| `NAVER_SEARCHAD_ACCESS_LICENSE` | 같은 화면의 액세스라이선스 | 필수 |
| `NAVER_SEARCHAD_SECRET_KEY` | 같은 화면의 비밀키 | 필수 |
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | developers.naver.com 애플리케이션 등록(검색 API) | 선택. 없으면 문서 수를 건너뜀 |

이 스크립트는 조회만 하고 광고를 만들거나 켜지 않습니다. 검색광고 비용은 광고가 노출돼 클릭될 때 나가는 구조라, 광고를 만들지 않으면 비즈머니가 쓰일 일이 없습니다.

## 실행

```bash
python keyword-research/keyword_research.py 캠핑의자 무선청소기 -o report.csv
python keyword-research/keyword_research.py -f keyword-research/seeds.txt --docs-top 150 --bid-top 80
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `-f` | | 씨앗 키워드 파일(한 줄에 하나, `#`은 주석) |
| `-o` | `keyword_report.csv` | 결과 파일. 엑셀에서 바로 열림 |
| `--min-searches` | 100 | 월간 검색수가 이보다 적으면 제외 |
| `--docs-top` | 100 | 블로그 문서 수를 조회할 상위 키워드 수(검색 API는 하루 호출 한도가 있음) |
| `--bid-top` | 50 | 입찰가를 조회할 상위 키워드 수. 0이면 건너뜀 |
| `--sleep` | 0.3 | 호출 사이 대기(초). 429 오류가 나면 늘리기 |

## 주의

- 검색광고 API는 힌트 키워드에 띄어쓰기를 받지 않아서 스크립트가 공백을 지우고 보냅니다.
- 서명 방식은 네이버 공식 샘플([naver/searchad-apidoc](https://github.com/naver/searchad-apidoc))과 같게 구현했고, 같은 입력에서 같은 서명이 나오는지 대조했습니다.
- 실제 키로 돌리기 전까지는 가짜 응답으로만 검증된 상태입니다. 첫 실행 때 응답 형식이 다르면 오류 메시지를 보고 맞춰야 합니다.
